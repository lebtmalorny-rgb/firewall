Для основного показа заполните файл параметров по [подготовке терминалов](01_Методика.md#f-prep). В карточках расширенных опытов значения запрашивает команда read. Номера портов в примерах — значения по умолчанию; сначала сверьте их с работающими службами.

**Главные границы:** host-firewall фильтрует вход на узлы. Он не заменяет Security Groups ВМ, внешний межсетевой экран, TLS или RBAC. В текущем коде SSH и ICMP разрешаются без ограничения источника, а клиентские сети могут получать прямой доступ к некоторым backend API. Эти особенности включены в проверки, а не скрыты за схемой желаемой архитектуры.

В разделе «Источники» указаны пути внутри исходных архивов и их SHA-256. В репозитории опубликован готовый комплект для испытаний.
